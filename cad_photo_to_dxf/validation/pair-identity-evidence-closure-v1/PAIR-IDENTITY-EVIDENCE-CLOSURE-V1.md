## Decision and verification

No code fix is justified by an omitted authoritative join: no preserved physical-instance labels or equivalence artifact exists for these records. Repairing the empty competitor coverage as if it proved no competitors would require a new independently grounded instance/competition producer, outside this bounded task. The smallest future boundary is a producer that accepts the existing raw member observations, group geometry and source raster (and, where independently available, vector ancestry), emits per-observation physical-instance candidates or explicit unresolved ambiguity plus equivalence/competition coverage, and binds that output to frozen A/B observation IDs.
