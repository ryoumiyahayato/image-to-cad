# LINE-INTEGRITY-AUDIT-D2

This read-only DEV audit qualifies a target before assigning any pipeline root
cause. The tracked registry contains ten coordinate-verified cases and four
retained diagnostic rejections. Runtime crops and visual matrices are generated
under the Git-ignored `local-artifacts/draftsman/line-integrity-audit-d2` tree.

The census finds two detection-fragmentation failures and one ownership-mask
loss. Seven controls survive end to end, often because contour fallback replaces
weak or removed native LINE evidence. Detection fragmentation is therefore a
repeated candidate, not a common failure family or a dominant root cause.

The coexistence of independent losses and fallback-dependent successes is the
main architectural signal: source continuity is not represented as an invariant
through all stages. No production algorithm, threshold, filter, topology, or
assembly behavior is changed by this audit.
