## Numeric model and limits

Use a small independent interval evaluator. Each finite binary64 input is treated as its exact rational value. Addition, subtraction, multiplication and division are evaluated over rational endpoints and rounded *outwards* to the adjacent binary64 enclosure; division by an interval containing zero is unresolved. Square-root bounds are checked by exact rational squaring. Transcendental angle bounds use an alternating arctangent series with a proved remainder, rational argument reduction and a rational Machin-formula enclosure of pi. No system `acos` or `atan2` accuracy promise is used by the verifier.

The intervals describe the explicit reference arithmetic chain, in the field's declared unit. They are not an assertion that every implementation of NumPy SVD, LAPACK, BLAS or libm lies within one ULP or any universal fixed error limit. Compatibility is conditional: *both actual frozen raw diagnostics must lie in the independently computed interval*. A backend result outside it fails with its original value and the bound retained. There is no fallback widening after observing the sample.

The reference chains are:

1. **Degrees:** finite original source chords -> norm/unit-vector intervals -> dot-product interval -> decreasing acos interval -> degrees. Competition subtracts the corresponding angle intervals; min/max propagate bounds. Use the same finite observed spans and all competing ports. Attached-axis separation and companion angles use the same unit-vector/angle chain.
2. **Dimensionless finite parameters:** actual strict native segment endpoints -> two-dimensional difference/determinant intervals -> Cramer quotients. Singular or insufficiently separated denominator intervals are unresolved. This applies only to diagnostic segment fractions; actual intersection points and finite geometry remain exact.
3. **Core common-axis point, px:** original finite arm sample coordinates -> centred 2x2 scatter matrix -> unique principal-axis normal projector in closed form -> sum of normal projectors -> 2x2 normal-equation solution. The spectral gap and final determinant must be separated from zero. This is the mathematical total-least-squares/least-squares relation, independently expressed without calling SVD/lstsq as an oracle.
4. **Core axis residual, px:** the same projectors and common-point interval -> each perpendicular squared distance -> sqrt -> maximum. All intermediate enclosures and conditioning diagnostics are retained. No sample-specific constant is inferred from the known 87 differences.

Intervals can grow for cancellation, nearly equal eigenvalues or nearly parallel axes. Such input is not accepted merely because two boolean results match. The implementation may report a numerical ambiguity/PENDING instead of accepting an ill-conditioned component.

Only these existing numeric leaves may differ between otherwise identical plans. A star denotes a validated list index, never an arbitrary recursive key match.

- `components[*].node_direction_evidence[*].all_pair_candidates[*].deviation_by_fixed_span_deg[*]`
- The same pair record's `competition_margin_by_fixed_span_deg[*]`, `maximum_pair_deviation_deg`, `minimum_competition_margin_deg`.
- The same four fields under `components[*].decompositions[*].T_assignments[*].direction_proof`.
- `components[*].decompositions[*].T_assignments[*].minimum_attachment_axis_separation_deg`.
- `components[*].original_core_evidence[*].external_axis_common_point_px[*]` and `axis_intersection_residual_px`.
- The same two fields under `paths[*].contact_continuations[*]`.
- `components[*].native_contact_check.pair_checks[*].finite_native_contacts[*].contacts[*].finite_segment_fractions[*]`; if a rejected record retains `unexpected_contacts`, its fractions have the same diagnostic-only scope.

Every other leaf, key set, list length/order and scalar type is strict. This includes original direction vectors/chords/spans, pixels/masks, complete source paths, node/edge/port IDs and chains, all endpoint evidence, native endpoints, `representation`, actual `point_px`, object identity/host identity, geometry lengths/widths, ownership, hashes, selected decomposition, reasons and all discrete decisions. A similarly named float elsewhere is not permitted to drift. Non-finite values are always invalid.

## Threshold protection

The existing 20-degree direction maximum, 18-degree competition minimum, 45-degree attachment separation, 12-degree companion maximum and 0.85-px cycle residual are unchanged. An inclusive upper gate passes only when the entire interval is at or below the existing threshold; a lower gate passes only when the entire interval is at or above it. A straddling interval is unresolved, never promoted by matching booleans. Definite failing alternatives remain failing. The same rule applies to finite-segment parameter bounds and determinant tests used to detect contacts. A cycle's common-point interval must stay in supported original black pixel cells, not merely have a black midpoint.

New producer guards only reduce adoption in numerically unresolved cases. Existing geometry fitting, source responsibility, attached-end construction and host geometry are not replaced by this task. All raw diagnostics remain in the plan; interval certificates and explicit numeric status are additional evidence.
