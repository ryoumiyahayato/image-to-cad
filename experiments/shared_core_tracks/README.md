# Shared-core cardinal tracks: research-only NO_GO

This experiment has **zero real recovery candidates and zero production
adoptions**. It is not registered in a normal converter, cache or DXF writer.
The existing r13 open-stroke and explicit source-region behaviors are unchanged.

Baseline: `d6d26c142f2d1998ef69ac181b18718dddb6d2d1`.
The executed proposal SHA-256 is
`0b357583d7a2f0aa39267307a782e82aec5890bc633df979526bf67257d5279d`.

## Question and result

Can a source-defined horizontal or vertical track retain every shared core,
short branch, guard and collar while replacing only independently supported
exclusive interiors? Source membership is frozen before a fixed-width LINE
check. Geometric contact, original-object identity and electrical connectivity
are separate fields; the latter two are not inferred.

The independent synthetic suite contains 23 sources. Eight research LINE
candidates passed source accounting, complete native black/white center
preservation and subsequent independent continuous geometry/contact/topology
review. These are synthetic evidence, not actual drawing improvements.

On the previously exposed real inputs, the one frozen producer run made 153
whole-parent calls (A2 113, HABS 40). Of these, 104 were already claimed or
protected; 44 completed the source enumeration with zero eligible tracks; five
retained their original `SOURCE_BAND_BUDGET` status. All original 24 complex
parents and the additional historical parent were included and completed.
No real track reached pen validation, no source retired, and no new DXF was
produced.

The separate source-only streaming audit first matched all 4,755 saved bands
and 43,734 run-ledger fields for the 44 completed parents. After freezing its
code and comparison, it fully enumerated 5,935 bands for the five budget exits;
zero satisfied the same necessary source conditions. It did not rerun the
producer, increase the budget or fit geometry. This closes that budget gap
only for the frozen cardinal contract, not for all possible curves or source
partitions. See `audits/README.md`.

## Files and separation

- `proposal.py`: the executed, frozen research method.
- `CONTRACT_DRAFT.md`: source and geometry contract, scope and budgets.
- `prepare_real_inputs.py`: immutable source-tile capture from registered
  originals and preserved whole-page ownership stages.
- `run_local_sweep.py`: the exact one-shot Linux research runner used here.
- `tests/`: independent fixtures, source/center auditors, continuous auditor
  and audit self-tests. No private source data are in this directory.
- `audits/`: the independent compact source-eligibility diagnostic.

Private input arrays, coordinates, preserved CAD, original scans, complete
results and logs are delivered separately. The public patch contains no real
source crops or actual NPZ data. Source membership and rejection evidence must
not be reconstructed from the figures alone.

## Supported execution scope

The measured environment is Linux, Python 3.12.14. Package versions are in
`requirements-research.txt`. This is an isolated research environment, not a
replacement for the application's requirements. Existing project application
imports are resolved from `cad_photo_to_dxf/app`.

The method requires complete, registered bitonal originals at an integer scale
of 2–16, actual current/visible masks and all protection masks. This run used
A2 200-to-100 DPI and HABS 400-to-100 DPI. ENV had no eligible captured tile,
no method invocation and no new regression conversion. Continuous synthetic
candidate verification here does not certify arbitrary scale/width combinations.

The exact runner has two known reuse boundaries, retained rather than
silently edited after execution:

1. It requires `controls.all_passed` but does not internally bind that report's
   proposal SHA to the current module. For **this run**, an independent binding
   audit proves equality of the control report, real freeze and delivered
   proposal. Any new experiment must explicitly check these SHA identities and
   freeze a new control report before invoking the runner.
2. It is not a general runner for inputs without registered originals. A
   future eligible tile with `native_scale=None` will fail its post-proposal
   native-mask construction. Do not use it for ENV/PDF/grayscale sources or
   claim support based on this run's empty ENV tile list.

## Replay without changing historical evidence

Use fresh output directories, never the delivered result directories. The
private bundle contains the exact input/source manifests and saved results;
reading or auditing those results does not require rerunning the experiment.

Synthetic controls, if a new replay is explicitly needed:

```bash
python experiments/shared_core_tracks/tests/run_independent_controls.py \
  --proposal experiments/shared_core_tracks/proposal.py \
  --repo . --output NEW_CONTROL_DIRECTORY

python experiments/shared_core_tracks/tests/independent_continuous_tracks.py \
  --controls NEW_CONTROL_DIRECTORY --output NEW_CONTINUOUS_AUDIT_DIRECTORY
```

Source preparation and the real run, only with the private registered-source
tree and newly verified control/source binding:

```bash
python experiments/shared_core_tracks/prepare_real_inputs.py \
  --evidence-root PRIVATE_SOURCE_REPLAY_DIRECTORY --out NEW_INPUT_DIRECTORY

python experiments/shared_core_tracks/run_local_sweep.py \
  --inputs NEW_INPUT_DIRECTORY --out NEW_RESULT_DIRECTORY \
  --independent-tools experiments/shared_core_tracks/tests \
  --controls NEW_CONTROL_DIRECTORY/summary.json
```

This is a saved research checkpoint. It authorizes no full-page adoption, no
main merge and no new local CAD task. Future work needs a genuinely useful
real positive, complete source/geometry evidence and non-target preservation
before a production adapter is considered.
