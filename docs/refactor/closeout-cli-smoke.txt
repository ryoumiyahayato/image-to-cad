usage: main.py [-h] [--version] [--headless] [--input INPUT] [--output OUTPUT]
               [--preview PREVIEW]
               [--paper-size {UNKNOWN,A0,A1,A2,A3,A4,LETTER,LEGAL}]
               [--paper-orientation {auto,portrait,landscape}]
               [--paper-width-mm PAPER_WIDTH_MM]

               [--allow-empty] [--report REPORT] [--debug-dir DEBUG_DIR]
               [--ocr] [--verbose]

Image to CAD: convert a photographed printed CAD drawing into an editable DXF.

options:
  -h, --help            show this help message and exit
  --version             show program's version number and exit
  --headless            Run without the GUI
  --input INPUT         Input JPG/PNG for headless mode
  --output OUTPUT
  --preview PREVIEW
  --paper-size {UNKNOWN,A0,A1,A2,A3,A4,LETTER,LEGAL}
  --paper-orientation {auto,portrait,landscape}
  --paper-width-mm PAPER_WIDTH_MM
  --paper-height-mm PAPER_HEIGHT_MM
  --allow-uncorrected   Continue when the paper boundary cannot be detected
  --allow-empty         Allow a successful empty DXF when no lines are
                        detected
  --report REPORT
  --debug-dir DEBUG_DIR
  --ocr                 Run optional production OCR
  --verbose
