## 产品要求未改变

以 [README 的既有产品要求](../../README.md#不可退回的产品要求既有标准) 为准：
- 表格、图签、数值、中英文正文与说明需要内容正确、排版合理、可改字符串和移动的原生 TEXT/MTEXT。
- 合理替代字体可接受；原字体完全复刻是可选增强，不是核心门槛。
- Logo、设计集团标志、签名等非编辑背景应独立、保真、默认受保护，不参与正文 OCR 替换。
- 工程符号保留外框、内部字符与关系，不能统一当普通文字或背景。
- 改字不得残留旧笔画或破坏邻近内容；DXF 程序读回、CAD GUI 和 DWG 往返分项验收。

这些是已有要求的恢复和明确化，不是本轮新增需求。本文此前“按需语义编辑”的表述已纠正，不能将可编辑文字降级为可选交付。

## 当前主线

S0 矢量目录页的 B 默认外观优于正常链路。主要机制是保留 PDF 原路径及原字形，而不是训练出新的工程识别模型。
A 已有实际 TEXT 编辑能力；B 默认字形仍是几何。只比较未编辑显示不能认定 B 在完整产品目标上优于 A。

整合方向是按内容用途分流：保留并改善语义文字编辑，吸收来源几何保真，独立保护非编辑背景。暂停追加小型数值专用训练，模型建议保持可替换。

新增 `tools/native_first` 为独立 CLI：原生路径导入离线执行；BYOK 接口只提供未经认证的文字建议。它是有限的导入部件，不是完整产品验收结果。
现有生产 GUI、扫描处理、OCR、FinalStructure、缓存、来源保护及保存机制未被替换。
真实供应商效果比较、自动文字替换 GUI、复杂 PDF、扫描语义重建、目标编辑器回存及真人净收益均未完成。

详见 [整合与勘误](NATIVE_FIRST_20261024.md) 与 [工具说明](../../tools/native_first/README_ZH.md)。
