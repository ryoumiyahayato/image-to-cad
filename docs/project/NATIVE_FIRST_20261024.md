# 2026-10-24：S0 对照后的整合与产品标准勘误

## 需求勘误：沿用旧标准，不是用户增加要求

本页初版使用“原生来源先保真保留，语义编辑按需添加”的表述。它只能描述有限的来源导入步骤，不能作为产品交付标准；对表格、图签、编号、数值、中英文正文和说明，可直接修改字符串及移动的原生文字一直是必需能力。

统一验收口径见 [README：不可退回的产品要求](../../README.md#不可退回的产品要求既有标准)。允许合理替代字体、字号和排版；原字体完全复刻不是核心门槛。Logo、设计集团标志、签名等非编辑背景应独立隔离、保真并默认保护，不应被正文 OCR 替换。工程符号须保留外框、内部字符与必要关系，不能统一当正文或背景处理。

旧交接已记录 P2B 在 E01/W02/W03 的 Logo、签名保真及透明图像依赖，以及 P18-A 的相关便携打包工作。这些是有范围的历史成果，不是本轮新提议，也不能不加核对就外推到全部来源。W01 仍出现 Logo 被识别成普通文字的问题；它表明该输入上的保护未成立，但本轮未定位到某个历史实现被哪次提交覆盖。

B 默认外观更忠实不等于完整产品优于 A；A 的实际 TEXT 编辑能力必须保留并与显示、内容正确性分别评价。轮廓分组、隐藏的替代 TEXT 和未编辑截图不能替代文字交付验收。

本次勘误只修改项目说明，不改变程序行为、历史实验数据或任何已验证/未验证状态。文档修正不等于 Logo 隔离、自动文字归属或跨编辑器问题已经修复。

## 决定

用户要求把最近 A/B 成果更新到主分支、整合可复用路径、允许用户自带供应商 API Key，并在保全后删除冗余分支。用户同时报告已删除 Windows 本地相关程序目录；不能继续假定原工作树/备份存在。

整合方向是：**按内容用途分流，保留原生文字编辑能力，利用来源几何保真，独立保护非编辑背景；模型作为可替换的建议组件。**
现有小型数值/分数/笔画专用训练继续暂停。不将这一预算决定扩写为所有机器学习不可行。
现有扫描链、DXF 读写、来源记录、校对、保存与回归设施保留。

## S0 实验到底证明什么

A 使用正常处理入口；B 从 PDF 原路径导入、保留字形，另由 AI 转录可选文字。
B 默认显示 4,707 个 LINE/LWPOLYLINE/HATCH，没有 IMAGE 底图；2,555 个源路径均有绑定。
89 条可选 TEXT 默认关闭，替代字体与源字形不同；字形几何不等于可直接修改字符串的语义文字。
在该矢量目录页上，B 默认外观明显更忠实。它不是任意扫描图重建、工程对象理解、完整文字编辑或真人省时的证明。
共同比较中的源墨迹超 1.5px 距离数 A=36,492/B=0，反向 A=101,333/B=0；这是后验图像描述，不是正确率。
源码和工作流也不同，不能把收益直接归因于模型智力或某一个模块。

## 当前整合

新增 `tools/native_first`，保持正式 GUI 路径不变：
1. `import_pdf`：去除 W01 固定尺寸、区域和源哈希的离线来源导入 CLI。支持范围明确；未支持内容阻止不完整导出。
2. `byok`：OpenAI 兼容 Chat Completions 与 Anthropic Messages 格式的文字建议接口，端点/模型/密钥环境变量可配置。
3. 原生保真核心不调用模型或 OCR，不需要 ChatGPT、Claude 或 DeepSeek 订阅。
4. API 发送默认关闭；不保存密钥、无自动改字/自动执行模型代码，未测字段不伪装成通过。

这是有限的导入与建议部件，不是 GUI 全面完成，也不是供应商效果对照或完整可编辑 CAD 验收完成。新增可选 API 不把正文和表格的可编辑性变为可选要求。本轮没有提供或读取用户 API Key，没有将真实图纸发给外部模型。
详细用法与适用边界见 `../../tools/native_first/README_ZH.md`。

## 分支和恢复

所有原有非 main 分支先保存在 `archive/20261024/<原分支名>` 标签，回读一致后才删除分支。
归档标签是恢复引用，不是产品 Release。独有提交不合并进 main 冒充已验收功能，也不因删分支而销毁。
逐项原 SHA、ahead/behind 记录见 `BRANCH_ARCHIVE_20261024.json`；执行日志在对应 Actions run。
主分支整合采用有期望 SHA 校验的正常快进，没有重写旧提交。

本机恢复边界见 `RESTORE_AFTER_LOCAL_REMOVAL.md`。只有 Git 跟踪内容可从 GitHub 恢复；私人技术小包不等于全部真实数据/模型/环境备份。

## 后续验收原则，不自动执行新任务

新方案必须同时说明：哪些内容能改字与移动，哪些背景已独立保护，哪些工程符号关系得到保留，以及实际保存/重开验证到哪一步。

对字体和显示的改进，不能以牺牲内容或文字编辑为代价；对文字编辑的改进，不能破坏 Logo、签名、邻近表框或正确符号。历史保护项不得因实验换了路径而从验收清单消失。

矢量页和扫描页分开统计。给定转录与选区的隔离样例不能冒充自动识别泛化，程序级 DXF 检查不能冒充 CAD GUI 或 DWG 往返。
本次文档勘误不启动新训练、转换、代码改动或下一 Goal。
