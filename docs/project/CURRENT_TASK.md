## 研发任务的中等规模交付标准

每轮围绕**一类能实际增加图纸内容的问题**，同时处理必要邻接来源、典型反例和真实CAD编辑。正常一次交付至少给出：

1. 具体新增或恢复的**完整可编辑对象**（不是新候选数、OCR次数或 HATCH覆盖）。
2. 同范围真实保存的 DXF、原图/输出对照；能冷读、操作、保存重开，其他旧正确对象保持。
3. 失败项目明确保留原来源并定位待修；禁止硬填文本、误连真实白缝、删除真实短线。
4. 代码变更、少量相关测试、远端 commit SHA；如同步受阻，保存私有可恢复检查点，不等登录超时。
5. 主线合并后删除已无独有内容的临时分支；不必等到整套产品达到 GO 才将已验证代码合并 `main`。

本轮的源码、实际 DXF 与独立编辑回读证据已经保存；版本合入关系以 PR #42 实际记录为准。后续仍保留 C08 的文字接触归属、尚未恢复的复杂连接／交汇、门窗符号、EBB-3，以及 INSERT 保存变换等兼容问题。C07 复用 `60f4e24` 的有限小环／四端口延续，本轮完成正式局部整合，不代表整处交汇或任意多路径分解全部解决。三行注释单 MTEXT 与备用 BLOCK 已作有限失败结论：若无与更普遍图块问题相关的直接新证据，不再为这一条注释单独开展多轮兼容性实验。
