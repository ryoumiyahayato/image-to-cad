## 交付和采用标准

每轮交付真实完整对象、同范围实际 DXF 与对照、必要删／移／改／保存重开、邻居保护和明确失败位置；候选数量、像素覆盖、OCR 调用数和测试数都不能替代实际内容恢复。禁止硬填文字、补封门洞、填白缝、删除真实短枝或把碎线包成 BLOCK 充当完整对象。

当前单位仍为**纸面毫米**；工程设计尺寸需要独立比例标定。LibreCAD 的 XDATA 与 `zscale=0` 保存限制继续单列，编辑后文件不能继承原始审核。
