# 验收标准（Acceptance Gates）

任一阶段宣称通过，必须满足对应范围的全部硬性门槛；未执行项一律标为 `NOT_RUN`，不得由其他指标推算或替代。

## G1 · 全页无缓存冷启动与双向残差门槛

- 使用**未参与规则编写与调参的陌生真实纯图像／扫描图**（涵盖中文正文、表格图签、工程符号与签章/Logo），不导入任何历史中间缓存或阶段检查点，经默认入口从头冷跑生成最终 DXF。
- 关闭一切参考底图及残余诊断图层（`REVIEW_SOURCE` 等），仅对正式输出的原生实体与受保护签章进行栅格重绘，与原输入图计算**双向残差**：
  - **正向漏画残差**：原图有效墨迹未进入正式 CAD 实体的比例与漏画集中区（明确披露，不得用残余图片遮挡）；
  - **反向误画残差**：越出表框、文字重叠、错误桥接及被切碎结构线的异常区域。
- 单纯的单元测试通过数、实体总数、OCR 置信分数或未关底图截图**不构成**质量验收通过。

## G2 · DXF 结构、可编辑性与保护完整性门槛

对实际保存后的 DXF 以新进程冷读验证：
1. **结构合法**：`ezdxf.audit().errors` 为 0，无非有限坐标、零长度或重叠重复实体。
2. **文字可编辑**：中英文正文、数字、编号与表格说明均为完整词句原生 `TEXT`/`MTEXT`，不拆成单字，不输出轮廓/图片替代；字号、宽度系数、对齐与旋转合理，无系统性越出单元格边框。
3. **结构线完整**：线条以单根中心线原生几何表达，保持真实开口与标准线宽；紧邻或穿过文字的表框线不得因擦除文字而被啃断。
4. **背景独立保护**：Logo、设计集团标志、签名与印章保留为独立原生几何或透明 `IMAGE`（随同目录完整交付），不误识别为普通文字。
5. **复合符号与补绘建议**：圈内字符、方框符号保留外框、内字与连接关系；缺角/模糊处的推测补绘仅写入可独立开关/修改/撤销的 `SUGGEST_REPAIR` 层，不得混作已观察事实。

## G3 · 目标 CAD 软件实操往返门槛

必须在真实目标 CAD（AutoCAD / 中望 / 浩辰 / LibreCAD 明确版本）中实测代表性整页输出：
1. 选中中文、数字及英文原生 `TEXT`/`MTEXT`，直接修改单字及整串内容，确认周围无旧字笔画残留、邻近表框不断裂。
2. 移动或删除独立线条、符号组与签章图像，确认其余非目标对象保持不变。
3. 普通保存、完全退出 CAD 进程并重新打开，验证修改后的文字编码、几何位置与图像依赖完整持久。
4. 如宣称支持 DWG，须对真实转换链与回存单独建档验证，严禁以 DXF 可读推论 DWG 通过。

## G4 · 平台交付与最终人工省时门槛

- **平台交付**：目标平台实际打包程序（如 Windows 便携包与安装包）通过干净环境启动、真实输入转换、中文字体注册与卸载验证；Linux 检查结果不替代 Windows 实测。
- **终极省工标准**：包含核对、错字纠偏、全部漏项补绘、保存与复查在内的**整页真人净修图时间 ≤ 同范围同质量从零手画时间的 50%**。未完成实际真人计时前，严禁宣称产品达到可用或省工 50%。
