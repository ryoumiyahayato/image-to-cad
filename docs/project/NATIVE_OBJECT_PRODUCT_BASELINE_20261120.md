## 1. 产品是什么

将**没有可复用矢量结构的扫描图片、照片或扫描 PDF**，以及适用的矢量/混合 PDF，转换为用户可以直接继续制图的二维 CAD 文件。面向用户的结果是**完整、合乎来源的、独立可编辑的对象**，不是原图黑色像素的一层描摹。

- 输入：图片／TIFF／PDF（支持范围以实测版本声明）；保留原图、页、原 DPI、裁切和坐标变换。未知工程比例不得猜测，允许先按纸面毫米输出。
- 输出：首要是可编辑 DXF；DWG 只有真实转换、打开和回存验证后才能宣布支持。
- 对象：合理完整的 LINE、ARC、CIRCLE、LWPOLYLINE、TEXT/MTEXT、INSERT/BLOCK 及其他经验证的 CAD 实体。用户能够选中、删除、移动、修改端点或文字，且不影响非目标对象。
- 识别目标：完整线段、墙边及门洞关系、门窗和设备/消防符号（类别须有依据）、房号和多行注释、引线和曲线、表格、图签、标注、必要的背景对象。工程语义分类是提升对象完整性的**手段**，不是在全部来源上强制推断工程身份。
- 缺乏可靠证据时：**正式 CAD 不猜画**；在可关闭的待修层、原图定位和结构化清单中完整标明，原始扫描作为独立参考保留。漏项和人工补绘一律计入后续修图成本。
- 已确认的 LOGO、签名等非编辑背景按用途分流，独立保护；不得冒充正式墙线、文字或图块。

## 2. 当前路线（覆盖旧设计中的相反要求）

**原图读入与追溯 → 高分辨率局部识别／可复用矢量提取 → 文本/普通线/复合标注/符号与背景分流 → 来源证据及上下文判断 → 完整对象组装 → 原生 CAD 输出 → 保存后独立复核 → 目标 CAD 真实编辑与回存。**

不能用 HATCH 铺色块、逐像素轮廓、碎线集合或仅一层图片**冒充**完整线、门、墙、符号和正式文字。HATCH 只有在原图确属填充且用户需要填充对象，或作为**明确标识、不计已重建成果**的参考／历史实验时才适用。

对扫描锯齿、墨迹毛刺、字体替代等，来源像素逐格相等是诊断而非整体成功标准；但不能借此掩盖真实漏墙、漏字、错数字、错误连接、封门洞、虚线变实线、保护区破坏和未经确认的拓扑补全。任何合理化重建应保留原始依据与编辑关系。

不把 HATCH 分区数、黑格覆盖率、MILP 分数、可读取 DXF 的实体总数、自动化测试通过数或脚本调用次数当作整体产品验收。它们可作为分层诊断和回归证据。

## 3. 完整对象与安全合同

1. **边界和文字一起完整：** 房号框不能只留下底边；多行注释不能缺行；设备标签不能凭前缀冒充完整。无证据时整组待修。
2. **对象归属：** 文字笔迹与边框、引线、交叉线、独立短划区分；完整对象能够操作，不留旁边碎片。不能只因两个图元视觉相交便推断有工程连接。
3. **文字：** 内容正确、真 TEXT/MTEXT、合理字号/间距/位置/对齐、可改字。一般字体替代可接受，字体误差必须与漏字及错字分开评价。
4. **符号和门：** 类型有同图图例/可验证上下文/原形依据；可成块独立操作。块内成员不过度碎片化，改单实例不得误改另一实例。
5. **保护：** 非目标成员、真实短划、开放白缝、LOGO和签名须保留；不能为了提高识别量调低防误画规则。
6. **审计：** 实际保存 DXF 冷读、独立渲染、原图到输出与输出到原图双向核对、真实 CAD 删除/移动/修改/保存退出重开。没有实测即 NOT_RUN。

## 4. 当前验收对象和人工作业标准

阶段目标是已冻结的真实旧图 **A2-SG-008.tiff 的连续四分之一区域**，原图 7200×4822，范围 [1400,1000,5000,3411]（坐标为原像素）。该区域的墙/门/消防或未确认符号/文字/引线等应完整记录和逐类处理。未确定的消防类别须调查图例，不可凭字母形状猜测。

正式工程师验收必须在明确目标 CAD 版本完成同范围、同最终内容质量的实际比较：

- 没有必须清除的无意义碎线、重复对象、伪 TEXT 和填色垃圾；
- 修图人工时间包含核对、纠错、全部漏项补绘、人工干预、保存和最终检查；
- 该总人工时间 **≤ 同范围同质量从零手画时间的 50%**；机器用时另列。
- 工程师未实际计时之前，不能宣称省时50%，不得因此扩全图。

继续使用9个已冻结真反例（房号210、三行 DN. TO/LIGHTS ON/1ST FLOOR、EBB-3、墙与门、交汇/短划等），需要同一个最终源码版本的**完整区域 DXF**证明累积改善，而不是把不同研究分支的成功数相加。

**精度先行：** 修复旧历史异常词框永久否决新完整证据；让新输入实际运行行域修复；分别获取210、三行注释和EBB-3的可靠文字证据；清理房号框及文字残余和穿越线归属。然后用单一版本输出完整冻结区域，逐项说明保留/合理替代/撤回/意外遗漏；增加目标 CAD 正常打开、操作、保存和重开验证。

1. 本文件是**新的当前产品契约**；与它相冲突的旧文档应有显式 SUPERSEDED 提示、迁往历史或删除非必要副本。
