# Image-to-CAD：精度研发与有效实验硬要求

> 用户指令补充日期：2026-11-17。适用于**已经获得用户明确授权**的 Image-to-CAD 识别、来源归属、几何重建与可编辑性精度研发任务。它不自动授权训练新模型、外传私有图纸、修改 `main`、清理历史或绕过安全/验收约束。

## 一、研发成果以实际能力变化为中心

**Image-to-CAD 的研发任务以可验证的识别和重建能力变化为主要成果。发现缺陷之后，Agent 必须优先进行代码修改、局部实验、整页转换及回归测试。报告、审计、兼容性检查和仓库同步是必要的辅助工作，不得替代精度研发。未经实际实验验证的方案不得宣称完成；失败实验必须保留代码、输出和证据，并继续尝试技术上合理的替代路径。**

**不要求失败实验必然成功，但要求 Agent 真正实施实验。每轮必须完成实际算法实验，而不是只完成关于算法的讨论。**

这里的“每轮”指一次用户明确交付的**精度研发执行任务**。仅请求讨论、只读审计、文档修改或GitHub同步时，不强行伪造算法实验；但是，不能把已授权的精度研发擅自降级成长期审计、汇报或等待。

## 二、禁止用“1+1=2”式玩具实验充数

**实验必须有真实的技术挑战和可判别的产品风险。** 不得将结果预先确定、与目标缺陷无关、只验证基础算术/语法/测试框架会运行的玩具实验称为“本轮算法突破”“有效精度实验”或“交付完成”。以下行为均不算本轮的有效算法实验：

- `1+1==2` 式恒真断言，或只验证函数能导入、DXF能打开、测试器能返回 PASS；
- 用硬编码真值直接生成预期答案，再验证自己生成的答案；
- 只在与真实失效机制无关的理想合成数据上取得高分，却未建立与项目真实样张的对应关系；
- 只比较实体总数、源码行数、报告页数、测试通过数量或渲染好看程度；
- 把已通过的旧测试反复运行，重新计为新增研发成果；
- 为凑进度而放松容差、删除断言、改冻结基线、隐藏残差、删掉不确定墨迹或猜测原图未观察到的结构。

**必要的单元测试、数学正确性检查、合成反例和环境冒烟仍可保留**，但只能是实验支撑、回归保护或工具检查，不能替代真实问题上的算法对照。并不要求所有实验都必须成功；要求它们能够真正排除错误假设、发现失败模式或验证可复用的恢复机制。

## 三、每轮有效精度实验的最低证据

1. **问题必须真实且具体**：指向已有真实图纸中的识别/绘制错误、被拒绝的来源成员，或与该错误机制明确对应的困难反例；写明原版首次失真阶段，未知时如实标为假设。
2. **有可执行的技术改动**：实际修改隔离代码，或实施与当前生产路径相关的可运行算法原型；留下源码差异、准确基线、依赖和重现命令。纯方案讨论不算实验。
3. **有真实正反对照**：相同输入及约束比较原版/候选；包含至少一个可复核的真实来源问题，以及足以暴露误接、误删、误认、错归属等风险的反例。合成样本可辅助，但不得单独代表真实CAD改善。
4. **有产物和可量测的判断**：记录真实输出、来源像素/原生PDF证据、CAD对象及几何误差、端点/开口/短划/文字保护和非目标影响。仅通过DXF审计或只看局部漂亮截图不够。
5. **失败继续推进**：拒绝候选、退化和中断都保留实际代码、日志、反例、参数和结果；必要时再试一种有技术理由的替代路径。不得把 NO_GO 改写成 PASS，也不得因为某旧报告未完成而无期限停止新实验。
6. **阶段清楚**：局部证据成立后才允许接入生产；接入后在同一冻结源码上执行受影响的整页转换、相关回归、非目标比较和保存读回。未到接入门槛则明确 NO_GO，不得将研究包伪装为本地可执行交接包。

## 四、交付与分工

每轮报告必须分别回答：真实问题是什么；实际做了哪些算法实验；通过/失败的正反证据是什么；恢复了多少**合理可编辑的逻辑对象**，增加了何种真实收益；有没有伤害旧正确项；距“陌生图纸首次转换后少量修复”的目标仍缺什么。**不以测试数量、实体数量或工作耗时冒充精度提升，不编造完成比例或天数。**

云端能够完成的源码研究、模型/算法实验、整页转换、回归和文件检查均留在云端。只有确实依赖目标 Windows/LibreCAD GUI 的选择、编辑、保存、移目录冷重开或真实启动行为，才交给本地 Agent；必须提供可下载的真实首件、依赖和一条具体可执行的验证指令。未产生合格新候选时，本机无新增任务。

本要求与 `AGENTS.md`、`docs/project/PRODUCT_INTENT_AND_KNOWLEDGE_PACKS_ZH.md`、`docs/project/AGENT_OPERATING_PROTOCOL.md` 和 `docs/project/ACCEPTANCE_GATES.md` 配合使用；不得以本要求为名降低来源真实性、保守回退和历史保护标准。
