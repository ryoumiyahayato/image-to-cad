# Image to CAD：产品意图、实施形式、知识包与 Agent 续研指南

> 更新：2026-10-24。文档属性：用户长期目标的**规范性备忘录**，并非已完成的架构或新的施工授权。
>
> 本次依据用户对此前实现形式的逐段纠正而编写；以既有 [README](../../README.md)、[执行协议](AGENT_OPERATING_PROTOCOL.md)、[验收门槛](ACCEPTANCE_GATES.md) 与 [当前状态](PROJECT_STATUS.md) 为关联资料。遇到实际代码与本指南冲突，须报告冲突并核实版本，不得假称代码已经满足指南。

## 1. 最终目标：结果正确、合理可编辑，不以“理解工程图”为必要条件

我们开发的是**自动图像/PDF → 二维 CAD 转换与修正系统**。用户提供矢量 PDF、扫描件、照片或混合图像后，系统应尽可能完整、准确地恢复原图中需要交付的内容，以合理的 CAD 表示保存，使其可修改、可修复、可继续制图，并尽可能减少人工核查、描线、重建与修正。**最终质量和人工劳动节省优先于转换速度。**

**不要求系统在语义上知道某形状是墙、梁、设备、轴承或哪种具体工程对象。** 只要来源内容得到正确恢复、采用适合用户操作的原生实体、能够继续编辑并保留可修复性，就已经具有产品价值。语义理解、领域识别、工程类别和模型推理是某些输入下的有效**手段**，不是所有输出都必须达到的先决条件。反过来，即便模型正确说出了“这是墙”，坐标、笔画、端点、文字或编辑属性错误，仍不合格。

必须区分：
- **内容准确**：文字字符、工程数字、单位、符号组成、墨迹边界和需要保留的结构没有被错误替换或遗漏；
- **实用编辑**：用户能改某一字、移动一个元素、修改一条线或一组相关对象，周围不被误改；
- **显示合理**：字形清楚、字号间距和布局协调，线宽与比例尽量忠实，但普通文字无需像素级复刻原字体；
- **来源与修复能力**：知道可见证据、猜测、来源图和 CAD 成员之间的关系，不确定处可以选择、修改、撤销、恢复；
- **劳动节省**：完整交付任务中实际减少检查、补绘和修正的负担；单项指标仅为诊断。

可编辑性和内容准确性**不能用更漂亮的默认画面交换**。对不需要编辑的非正文对象则没有强制转换为 TEXT 的要求。

## 2. 既有要求：按用途表示，不是统一全部矢量化/文字化

| 内容用途 | 合格交付方向 | 常见失败 |
| --- | --- | --- |
| 表格、图签、图纸目录、中文/英文正文、编号、数值与普通说明 | 识别完整字符串，输出真正的 TEXT/MTEXT；正常可读字体、合适字号、字间距、对齐、旋转和单元格尺寸；可改单字、改单行、整体移位 | 仅有轮廓/图片/GROUP；OCR 把 1 写成 7、分数丢斜杠；字越框；替换后留下旧字笔画 |
| Logo、设计集团标志、签名、印章等非编辑背景 | 单独划定归属，保留可靠原生几何或独立透明图像并保护；位置和外观稳定；随 DXF 打包依赖 | 将 Logo 当正文 OCR 成字母、拆坏标志、签名被印刷文字替换、修改正文时误删 |
| “圈内 R”、方框设备符号及其他复合工程图案 | 保留外框、内部字符、相对位置与连接，按实际操作需要组合/成块 | 只输出 R 而丢圈；把方框加字当普通一行文字；图案碎片导致难以选择 |
| 普通线、圆弧、轮廓、填充、表格边框 | 用 LINE、ARC、CIRCLE、LWPOLYLINE、HATCH 或必要 BLOCK 表示，避免无意义重复/碎片，保持开口和节点 | 双侧轮廓代替简单线、重复实体、误桥接、重叠填充、过度抽象而丢源线 |
| 残缺、不完整、难以判读区域 | 保留实际可见证据，允许标记清晰的候选补全，独立编辑或弃用 | 以“自然连续”伪装成真实已观察笔画，捏造数字、图纸比例或隐藏结构 |

**区分类别需要技术机制，但不要求理解其完整工程含义。** 例如程序可以根据重复图案、字符行形态、位置上下文、PDF 绘制路径和相邻表格约束提出“疑似 Logo / 疑似普通文字 / 疑似工程符号”；不确定时可保留来源并让用户选择。不得让 OCR 的高分或单一视觉模型的标签直接决定删掉其他表示。

关于字形：**原字体完全复刻是锦上添花**。正文要求内容正确、字体可读、合理排版和直接可编辑；Logo 和签名则允许几何/图像保真，不要求能单字修改。这是项目既有要求，不是 10 月 24 日新增条款。

## 3. 当前真实程度：设计意图与实现事实分开

用户原先构想了“**统一骨架＋可插拔领域知识包**”，但截至本备忘录，**一套完整统一骨架仍未真正建成，也没有一套被证明有效、可复用的领域知识包体系**。现有 GUI/处理链、不同研究模块和新 native-first CLI 是部分能力和技术资产，不能合并统计成已完成的总体框架。

已知有限事实：
- 正常链路已具备部分可编辑 TEXT、几何、来源记录、缓存、校对与 DXF 导出等能力；不同来源的质量仍有限。
- S0 A/B：B 因直接保留原 PDF 路径和原字形而默认显示更接近来源；其字形轮廓并非默认可编辑文字。A 有原生 TEXT 编辑能力，但内容和排版有问题。两者不能只按截图胜负确定整个技术路线。
- 已有基于给定转录和选区的隔离编辑样例可以把表格文字变成 TEXT、修改和移动；它不证明跨来源自动定位、识别、GUI 或 DWG 保存往返。
- P2B 等历史阶段记录了特定来源 Logo/签名保护及便携依赖打包，不应把旧要求反复当新方向；也不能把特定来源的成功外推为所有来源通过。
- 暂停继续原样训练近期小型数值等候选，是按证据和预算作出的决定；它**不等于机器学习一般性无用**。

进入新任务先核实当前代码和最小可恢复输入。用户报告曾删除本地程序文件，不能假定旧 Windows 工作树、真实资料、环境和未提交数据仍在；GitHub 跟踪内容、私人资料归档各自独立核对。

## 4. 实现逻辑：结果导向的组合处理，而不是语义理解强制流水线

以下是建议的**目标接口设计**，不是断言已经完成的正式软件架构。

### 4.1 输入事实与坐标层

保存原始 PDF/图像引用、PDF 原生绘制对象、完整可见页像素、页坐标至 CAD 坐标映射、单位/比例来源和必要的渲染状态；混合页允许按对象或区域组合原生 PDF 提取与像素检测。不必先把高质量原生路径全部栅格化后重识别。未确认真实工程比例时保留纸面坐标，不伪造 1:1 工程尺寸。

### 4.2 候选提取与可观察信息层

原生路径解析、线/轮廓/曲线提取、OCR 与可选 ML 可并行提供候选。每个候选至少能回溯：源页面及坐标、像素/路径支持区间、来源是否被裁剪/覆盖、候选类型、置信或不确定原因、与已输出对象是否冲突。不要因为路径被检测到就假定它是应当全长导出的工程实体。

### 4.3 用途与所有权层

在**普通文字／非编辑背景／工程符号／普通几何／未决**之间建立互斥或明确可叠加的使用归属。关键不是给每个元素一个工程学语义名称，而是回答“该画什么、谁负责可见墨迹、改它时影响谁、哪些保持不动”。

- 文字候选替换为 TEXT 前，先确认原字形对应的完整笔画区间；不能留下孤立旧字笔画，也不能误遮住格线、背景 Logo。
- Logo 和签名有独立保护权，普通 OCR 不能默认覆盖。
- 表框与文字、复合符号的外框与内部字符，允许关联但不必同化为一个巨大不可编辑对象。
- 来源存在多个路径重复表达同一笔画时，记录承担关系，避免同批新增候选重叠。

### 4.4 合理 CAD 表达层

优先生成可正常操作的原生实体；只有具备充足来源或规则约束时才合并片段、拟合单条带宽线、重建整组几何。**把笔画合成一条线是合理目标，但并不是所有输入都必须硬做成功的目标**。证据不够时允许保留较细粒度、仍可编辑的合法 CAD 内容及来源，而不能为了凑“1 条 LINE”删掉正确双线、开口或细节。可以保留复杂背景为独立图像或原生几何，但不能以整页底图充当默认 CAD 结构。

### 4.5 可编辑文字恢复层

将流程拆为：文字区域发现 → 与背景/符号区分 → 字符串识别 → 完整原字形归属 → 字体和布局求解 → 原生 TEXT/MTEXT 实体 → 旧可见字形完整退场 → 保存读回/编辑复查。

同一段长说明必须允许修改其中一个字，不必删除整段轮廓后重写。可采用合理的替代字体并依据文本框约束选择字高、宽度系数、对齐、基线与间距。不能拿“文字轮廓组成一组”作为该层验收结果。

### 4.6 校对、撤销和交付层

用户应看到已确认对象、未验证对象和建议补绘的差异；可以开关、删除、微调、接受，且不会毁坏来源证据。最终以**实际保存的 DXF**、新进程读回及目标 CAD 软件的编辑/重开检查为依据。需要 DWG 时通过受验证的转换链另行验收，不能换后缀伪造或把 DXF 可读推断成 DWG 已通过。

## 5. 不确定几何：尽量替用户完成可以合理完成的部分

用户明确希望：缺角、断边等可合理推测的位置，系统可以提出一段**自然衔接的候选 CAD 几何**，减少人工补线。它不是必须一直显示虚线或永远拒绝建议；但需要作为独立、可编辑、可取消的**推测对象**保存，不得混成“原图实际存在”的证明。

建议区分：
- **OBSERVED**：有可见源路径或像素支持的成员；
- **INFERRED_PROPOSAL**：依据连续性、几何规则、重复结构等估计出的候选，记录来源区域和依据；
- **USER_ACCEPTED**：经过用户接受后的修订；
- **UNKNOWN / NOT_EVALUATED**：输入不足、结构无法判断或未运行。

候选可在用户选择的预览/交付模式中按自然线型显示，也可在单独图层一键关闭、删除或修改；默认显示策略应当可配置。无论视觉上多自然，内部仍要保留推测来源与撤销能力。不能全页无约束连接断点，不能推断并静默改写图中看不见的数值、工程比例或设计意图。

**风险与实用性同时考虑**：不能因少数复杂对象而要求全部图纸达到完美工程语义；也不能因“自动补全省事”而隐藏未经验证的关键错误。

## 6. 领域知识包：人类制图规则的机器可执行表达，不是提示词合集

用户最初的知识包设想**并不以让通用 AI 读取为前提**。它首先是将人类在制图、编辑、检查中遵循的规则，转换为机器能解析、推理、执行或验证的形式；必要时才向模型提供简化规则作为辅助。

**期望的知识包合同（未来设计建议，尚非已实现 schema）：**

| 部分 | 应表达的内容 | 机器使用方式 |
| --- | --- | --- |
| manifest 与版本 | 适用领域/图型、输入条件、依赖、规则版本、许可、冲突优先级 | 确认适用范围和可恢复性，不误调用 |
| 对象表示 | 常见符号、文字/背景类型、构件所需几何、相对关系、合法 CAD 表达 | 生成候选、关联与组织，不要求每项都有工程名称 |
| 制图规则 | 线型、笔宽、边界、闭合/开口、尺寸和单位关系、对齐、重复/间距 | 提供约束、推断允许范围与优先级 |
| 风险和不确定策略 | 何时可补绘、何时只提示、何时弃判；可关闭候选与禁止修改的内容 | 风险分级与来源保护 |
| 校验器和错误实例 | 来源几何关系、TEXT 必须可编辑、Logo 保护、符号完整性、非目标保持、DXF 往返 | 确定性检查和可复现回归 |
| 评价与样本 | 正例、反例、合成/真实来源权限、冻结 A/B/C、度量及人工核查成本 | 决定知识包是否真有价值 |

知识包**不是**特定模型的 prompt，也不是把专业教科书原文堆进去，更不是一个未经证实的完整世界知识库。它可以独立用于规则检查、对齐、候选过滤、CAD 对象生成；通用模型、轻量模型或人工工具只消费相关的机器可读部分。

应当先在一类窄但有价值的任务上实现一个**有可运行规则、可追溯证据、可失败反例**的最小知识包，再验证跨设计是否真减少错误和人工工作。不要因为“知识包”听起来完整，就先扩建十几个空领域目录或重新训练多套模型。**截至本指南没有完成的有效领域知识包，必须保持设计中状态。**

## 7. AI 与机器学习：各自承担局部能力，不能成为唯一执行核心

用户既不认为一套黑箱模型能包办一切，也不认为纯机械规则能处理全部真实图纸。建议按**任务需求**选择能力，而非按“自研 vs 通用 AI”决定：

- **确定性层**：PDF 与像素证据读入、坐标换算、现有可验证的几何提取、DXF 写出、来源身份、实体变更、撤销、文件审计。能确定就不必调用 AI 重新猜。
- **OCR 与视觉估计层**：负责字串候选、区域/角色提示、符号形态或局部关系，不直接因为输出高置信就删除原像素或改写工程数字。
- **专用机器学习层**：仅当具体任务有合规数据、独立真实收益和旧内容保护证据时加入；它可以提供概率、分组和候选排序，不要求独立生产整个 CAD。
- **通用 AI 可选层**：按需做任务拆分、上下文建议、候选解释、结构化转录或脚本提案；返回**结构化建议**，由本系统的约束、来源证据、编辑和保存检查决定是否采纳。不要求所有供应商达到 Codex 级推理/编程水平。
- **人工交互层**：处理输入本身不可辨、风险高或规则难以决定的少量对象。目标是让人工在已有候选上选择/微调，而非重新绘完一页。

低能力模型也应当能使用最小的“图像输入→结构化识别候选”路径。软件可用裁片、类型化接口、字典/领域规则、几何一致性和回退来**弥补流程缺口**，但不能凭空弥补源信息或模型无法读出的事实。接口应适配多供应商；API 仅是可替换能力，不能把项目缩成“上传图片→转发 API→下载 DXF”的薄壳。

外部模型不授权发送私人图纸，不默认远程推理；无需模型时基础导入、编辑、验证仍应能工作。

## 8. 验收合同：从用户实际修改任务反推技术实现

每项新方案都必须继承旧需求和已知保护项，分层记录**局部研究成立、实际 DXF 改善、正式入口改善、跨编辑器通过、真人劳动节省**。未运行标 NOT_RUN，不自动补通过。

**最低回归操作示例（按适用来源选取）：**

1. **正文改字**：将可确认文字“电气”改为“水电”，或只修改长说明中的一个字；保持可接受的字体、字号、间距、位置；保存的 DXF 必须是真正的 TEXT/MTEXT，新进程读回内容正确，旧字全部退出，邻近表框与非目标实体不变。
2. **移动**：独立选择一行说明/一条线并移位，再保存、重开、撤销或恢复；不需要删除整组字形来改一个字符。
3. **背景独立**：Logo、设计集团标志和签名在文字提取、修正、移动后完整保留；不误变成普通正文；透明图像依赖随文件交付。
4. **工程符号**：圈内 R、设备边框、字符和必要关系保持；不能仅用“识别到 R”算成功。
5. **残缺恢复**：实际可见部分与推测补绘分别记录；用户能关闭、接受或修改补绘；严禁把全局桥接或推测数值冒充来源事实。
6. **跨文件/软件**：独立 DXF 读回与渲染、目标 CAD GUI 的打开/修改/保存/重开，以及 DWG 导出与往返分别报告；不能用一个代替另一个。
7. **实际劳动**：报告仍需手工核查/补字/修线的对象数量、错误提示和弃判，以及有条件时的真人操作时长；不能用训练成绩、对象数、合成 F1 或默认截图代替。

支持范围要分清原生矢量、纯扫描、混合 PDF、高清/低质来源；同一张曝光开发图不能当独立 C。保护既有正确项优先于追逐局部得分；但**研发阶段允许可撤销的局部候选和有风险标签的假设**，不应把它们一律当成正式自动修改要求。

## 9. 给后续 Agent 的行动顺序与防偏离机制

此文档本身**不授权**重写架构、开始模型训练、调用付费 API、恢复数 GB 文件、执行转换或修改生产代码。收到实际任务后：
