2. Candidate-box fitting contributes to apparent enlargement. W01 TEXT 814 occupies
[1107,400,145,45], while dark source ink inside that candidate spans 133x32 px.
TEXT 816 ('Project Name') occupies 112x35 px versus source ink 97x23 px.

LFF bounds exactly fit those candidate boxes; there is no unexplained extra exporter
scale in these samples. Candidate padding and box-to-visible-glyph fitting enlarge
letters, and narrow width factors (e.g. 816 = 0.407942) squeeze the English labels.
This explains the sampled crowding; it is not a claim about every reported overflow.

intact M-in-box plus independent adjacent 2. A00 is TEXT 'SL', without its original

Each contour record matches an original cached FinalStructure path index.
