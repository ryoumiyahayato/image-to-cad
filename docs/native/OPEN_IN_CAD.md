# 工程师试用：打开说明

**用途：发现修图问题；工程师实测状态 `NOT_RUN`。当前整体 `LOCAL_NO_GO`。**

1. 将受控试用包完整解压到一个新目录。保留主 DXF、同区域原图、字体及许可证、待修索引和审核文件。原始文件不要覆盖；在 `working/` 中保存你的副本。
2. 本轮目标为 **LibreCAD 2.2.1.6（Linux x86-64）**。打开主 DXF，缩放至全图。导出是 **R2013/AC1027、纸面毫米**；普通保存可用 **R2007/AC1021**。不要在不知比例时据此输入建筑实际门宽或墙长。
3. 先对照原图检查区域、文字和门洞。改字时选择可用的 `wqy-microhei`，记录实际字体、字高、宽度及行序；配套 `DejaVuSans.ttf` 是导出度量资源，不保证 CAD 自动采用。缺字、越框和重叠都记录，不以字体名字相同代替检查。
4. `REVIEW` 是待修导航层，默认隐藏、冻结、锁定且不打印。需要定位问题时临时显示，编辑正式对象前恢复。不得删除参考图或待修证据来减轻表面遗漏。
5. 按真实工作修**整个冻结区域**：找遗漏、补绘、纠正文字与连接、清理不合理对象、处理格式、最终核查。在[试用记录](ENGINEER_TRIAL.md)中计入全部工作和停顿；先记录最高成本位置，无需等待算法完美。
6. 完成后普通保存为 `engineer_edited.dxf`，退出CAD再打开该文件；确认改字、移动、删除保持，邻近门洞、文字和其他墙线未变。另输出一份打印预览或PDF，检查导航层和文字没有混入/裁掉。

**已知兼容边界：**该版本普通保存会丢失来源XDATA，改后文件须重新审核；门/房号INSERT可能写出 `zscale=0`，已证实会令 FreeCAD 导入丢失样例几何。因此保留普通保存原件，在跨CAD交付前进行独立检查；任何兼容修复副本必须另命名、重新记录哈希。不能把二维截图正常当成跨CAD通过。[详情](CAD_COMPATIBILITY.md)

**交回：**实际修过的DXF、计时记录、失败位置及截图、最终核查记录。未开始就保留 `NOT_RUN`；八项指定删移练习不代替全区域手画与修图工时比较。
