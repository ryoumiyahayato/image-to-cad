and common-alpha field failures are retained as historical experiments. They

The adoption and saved-binding schemas are `v4-bounded-source`. No new bounded

entry method whitelist. Old historical acceptance is not a new exact verdict.

## Independent gates

1. The explicit ID/index/actual-object host identity must agree. New shared
   vertices require a fresh finite pointwise original-ink domain. Existing
   endpoints and vertices are retained. Old native objects are never edited.
2. Every complete target retains all original source edges. Necessary prior
   portions retain their complete old object identity, exact finite geometry,
   original source subranges, same-arm exits and independent core walks.
3. The influence domain includes finite target geometry, original direction
   observations, all failed/short/truncated direction reads and predeclared
   continuation corridors. Final complete model reads recheck exclusions of
   remote old-object failures. A failure intersecting any used evidence cannot
   be dismissed by being outside the picture window.
4. All fixed sections are remeasured with the complete finite context. Every
   eligible interval is retained, including empty intervals. Each eligible
   section's own black cells must be covered by its own body. Every actually
   observed white section cell, including an ineligible section's whites,
   remains a common-white constraint. The old aggregate constant-width receipt
   is retained separately from the new field.
5. Circles use actual finite CIRCLE center/radius and INSERT transforms. An
   independently replayed historical identity, exact finite-arc support and
   new radial bounds are separate gates. Only explicitly bound original ring
   cells can be assigned to a circle, and every query must be authorized by its
   finite source domain. A tangent, chord, old PASS, or OCR result is insufficient.
6. All connected original black cells in the complete model window and all
   white observations are checked under one complete parameter vector. A
   numerical search can propose a vector; it cannot authorize membership.
   Exact rational/algebraic predicates must recheck every claimed witness.
7. Source edge ownership is independent of width. An unassigned short branch
   remains pending even if a broader width envelope could cover its pixels.
   Boundary exits need the same bound source arm on both sides or a certified
   original finite circle arc. Unknown exits and clipped observations remain
   pending. Observable continuation alternatives reuse the same independent
   knot bounds; no new endpoint-width freedom or residual-fitted widening is
   introduced by an extension hypothesis.

## Meaning of results

`PASS` of this source model is one gate. Complete graph direction uniqueness,
text/source conflicts, prior finite contacts, full saved membership, actual
saved source reconstruction and old-object preservation are still required.

An exact black cell outside every strict upper envelope disproves only the
declared finite family for those inputs. Search exhaustion is `PENDING`.
Missing prerequisites are `NOT_RUN` for the joint solver. None of these implies
that the scan is intrinsically ambiguous or that a residual belongs to a tail.

The runnable checkpoints save original inputs, code identities, actual writer
and fresh-reader outputs, and a manifest before subsequent long work. Source
stage and each original probe build their own graph/owner/plan. Existing 436
formal objects, 48 REVIEW entities and 55 named blocks are protected by actual
persisted full tag records. Actual delete/move/reopen exercises occur only for
newly adopted native objects; a newly executed zero-adoption run records those
exercises as not applicable. An unexecuted stage is always `NOT_RUN`.

This experimental branch does not merge main, run a GUI or claim Windows
validation. The parallel Issue 61 ordinary outlet keeps its independent scope.
