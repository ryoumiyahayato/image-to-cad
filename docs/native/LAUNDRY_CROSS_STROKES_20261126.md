## 一、三条短划：交叉墨迹分别承担编辑责任

实际阻塞在完整笔画的交汇追踪与独立采用之间：短划与已恢复长曲线共享交叉核心，旧流程没有将完整短划以独立责任交给正式原生对象采用。修复复用原图路径与交汇证据，不先判断笔画的工程含义。

[共同几何规则](../../cad_photo_to_dxf/app/native_objects/transverse_stroke_geometry.py)要求短划两端都是来源可见自由端点、完整路径有连续原墨迹、正反向追踪一致。交汇处分别核对短划和另一条完整曲线的两侧方向及竞争配对，检查实际跨越的来源像素；不能把整个多分支核心放入一个对象，也不能因换追踪方向就忽略已有竞争。还须绑定已经独立采用的完整曲线，保存后重放同一来源责任。

三条目标各导出一条完整 LINE，从真实上端点到下端点；没有用定位裁框截断长度，也没有拆成一串独立碎线。最终 ID 分别为 `CONTACT-f78821d866d6`、`CONTACT-68d382ce17e1`、`CONTACT-8463cd65a6ce`。这些 ID 仅用于结果账本核对。
