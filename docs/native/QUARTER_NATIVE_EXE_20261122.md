## 本轮修复的实际接入缺陷

- 普通与有界流程共用完整路径采用和旧 LINE 退休逻辑；最终完整组失败时撤回新组并回滚退休，避免局部能出、整区丢失。
- 修正新鲜文字的 tuple/list 合同及 Windows 证据路径序列化；保留严格来源核验，不用冷读覆盖后续真实变更。
