## 通用实现与失败边界

1. **完整图线。** 原图来源图按方向连续性及有限分叉证明追踪到实际端点或可靠圆边接点。裁框／ROI 边缘不是终点，字框内字形短枝的自由末端不能证明独立图线。可靠曲线输出独立 LWPOLYLINE，不收入文字或圆标记图块。
2. **共享接触来源。** 文字和线可相交、可共享扫描墨迹。派生识别图只排除有证图线范围，原图不变；断裂字脚、Y 上支、连字符、逗号、引号及普通 O／0 按原图保护。不填白缝、不以派生处理证明缺字。重复横划 token 仅在原图确为一条连续中线笔画时规范化；有白缝的两条横划分别保留。
3. **完整单行。** 一个成功标签输出一个 TEXT，原始转写、全行字形／标点、位置、方向和整体布局共同核验。接触分支的 Tesseract 词级总分作为参考；PP 每字最低 0.95、平均 0.98 保持。宽原始观察中仍有字母数字后缀且候选外有原墨迹时，否决窄前缀，不直接填入答案。案例编号、坐标、预期字符串和工程语义均不进入采用逻辑。
4. **精确原像素责任。** 重放通过的完整字形／标点 RLE 用于邻圆保护，避免文字矩形占掉独立圆边。旧字形碎段只有与新 TEXT 承担的完整原组件逐像素匹配、且不含图线／共享来源时才退场。缺证继续保守保护原对象。
5. **真实白缝。** 新门只对已重放分区中的独立邻圆做有界原图核验；只有原字形与完整圆边确有白缝时，才要求既有字体的整体 TEXT 轮廓不产生新接触。真实原图接触及 O／0 自身圈不误拒。当前字体及唯一一次有界替代字体试验均未解决 CT03，已停止布局试探，没有新字体、畸形缩放或逐字拆分；可靠转写保留为待修。
6. **实际保存与检查点。** 冷读先重放原始来源，再以保存文件中实际 TEXT 的位置、字高、宽度和旋转核查白缝，不能只重算侧车预期。接触路径由实际 DXF、侧车和采用记录三方发现并重放原图及完整保存几何；跨来源图比较真实像素邻接，不混用整数边号。完成阶段绑定新增代码依赖，旧完成检查点不得补造新门记录或绕过核验。

完整端点、外部分叉、字符／标点或布局关系未证明时继续待修。一个位置须文字与线同时成立才完整；删除文字后保留应有穿越线是正确结果，不能要求整个字框变白。
