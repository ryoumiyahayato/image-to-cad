## 整行布局与资源

既有正确文字继续 `I2CAD_TEXT`／原 DejaVu 资源。仅在默认布局会闭合有证白缝时，对一个完整 TEXT 尝试固定 `I2CAD_SOURCE_ROW` 资源，在原字高、字宽、整体位置、方向和逐组件位置约束内拟合单一变换；没有逐字符移动、缩放或工程语义补全。原图及圆、引线和下划线不移动。

固定 upstream 是 `hikikomori82/osifont@2e9aa86a8a09b044e08c00f5a4a2505dc3ca9f6e` 的 LGPL-3.0 字体例外版本。派生资源对全部字形应用相同的 CAD 度量转换；统一间距由整个源字库统计得到，不使用目标编号、原图坐标或验收字串。资源文件：

- `resources/fonts/osifont-cad-metrics.ttf`；STYLE `I2CAD_SOURCE_ROW`。
- `resources/fonts/I2CAD_SOURCE_ROW.lff`；供 LibreCAD 同名字体使用。
- `resources/fonts/osifont-cad-metrics.LICENSE.txt`；导出为 `FONT_LICENSE_I2CAD_SOURCE_ROW.txt`，包含原许可、完整许可条款及修改说明。
- `resources/fonts/source-row-font.lock.json`；准备步骤记录实际生成资源与依赖。

唯一身份定义为 `app/native_objects/source_row_font_registry.py`。`python scripts/prepare_source_row_font.py` 下载固定 upstream 并确定性构建；已有资源可用 `--offline` 验证重建。字体二进制与私人图纸不进入公开仓库。实际源输出和 Windows EXE 必须采用同一新版 TTF/LFF/许可指纹。既有 DejaVu 跨平台历史资源差异保持单列。
