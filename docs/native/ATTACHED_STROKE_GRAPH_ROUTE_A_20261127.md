## 已执行的诊断与两种解释

解释一是原图来源图仍保留必要信息，而旧规则只接受两个自由端、完整四向配对和
无内部循环，不能表达本组附着关系。解释二是构图合并、丢边或局部环路已使笔迹
不可区分，当前材料不足以形成完整对象。

对固定原图、旧主 DXF 和原始来源图逐项核验后，本组支持解释一：全部外部边、
真实自由端、三个三向附着接点以及已采用主路径的交点仍在。剔除正式主路径自己
已证明的外边责任后，余下组件是 10 边、11 节点的树。三个三向点的全部选择组合
产生 27 份完整分解；每份都能覆盖这 10 条外边并产生四条路径。因此恢复数量和
边覆盖本身不能证明选对了笔画。

旧方向观察会跨越相邻接点继续走，导致其中一个三向点偏转达到约 24.38°，超过
旧 20° 门。另有交点包含一个 1×1 栅格小环。回看未改动的原始墨迹，小环内部
没有白洞；较大的真实白区仍存在。这里没有把所有循环统一删除，也没有把第一次
拒绝误写成唯一障碍。完整诊断、每个端口的旧配对结果和全部替代解释保存于私有证据。

## 新模型：有限边方向、完整分解、共享实黑交点

新增 `app/native_objects/attached_stroke_graph.py`；旧自由端短划、原配对器及其
20° 偏转门、18° 竞争余量保持原样。

1. **正式前置承担者。** 只读取已实际采用路径的完整 receipt、原始像素路径、
   来源 crop 和实际几何。旧对象的身份必须唯一；同一来源端口若被多个正式对象
   声明，整个组件拒绝。未采用的候选不具有该权限。
2. **不越过接点的方向。** 每个端口观察 6、8、12 px 的有限原边，实际下一节点
   到达后立即停止；每个观察弦至少 4 px。本阶段新证明的残余横穿对和三向连续对
   在三个尺度下均须满足偏转≤20°、双端竞争余量≥18°；附着支臂与连续轴的最小
   夹角≥45°。已有 owner 自己的配对复用前序独立证明，纯二端口节点按拓扑唯一
   延续，不由这套有限方向门重新证明。所有相关端口都参与竞争，包括过短而无法
   判方向的第四支臂。这是不同的观察模型，不能称作旧配对全通过。
3. **枚举整体责任。** 枚举每个三向点的连续对与附着支臂，走完全部真实自由端或
   有来源的附着端，要求全部外边恰好归属一次。仅一个完整方向分解可行才继续。
   组件上限 32 边、32 节点、240 px，组合上限 512，实际最多五个三向选择点；
   每条完整笔长须在 20–120 px，超界保留 pending。组件须含三向接点，存在独立
   几何循环的残余宏观图或未支持的端口配置不在此树模型的采用范围。
4. **区分实黑小环与白洞。** 原 core 的所有像素与全部邻接保留，所选分解涉及的
   全部简单 core 编码留证。core 上限 64 像素、12 px 且不超过局部笔宽的三倍，无藏在 core 内的
   真端点。允许的栅格循环秩最多为 1；循环还须为四端口，原墨迹无白洞，外臂轴线
   交会最大残差≤0.85 px。真实孔、未解释分支或更大结构保持拒绝。
5. **完整独立几何。** 自由端固定在真实来源端点；附着端落在已共同证明的完整
   host 的实际有限线段上，位置还须处于原实黑 core。在固定来源采样顶点和端点
   集合内，求满足来源门的最少线段 LINE 或开放 LWPOLYLINE；每条线段经过的全部
   闭像素格必须为原墨迹，最大来源误差≤1.5 px。反向输入采用相同的规范拟合方向。
   全部简单 core 编码留证，其所有样本须在 1.5 px 门内兼容同一选定原生表示；
   这不是将各编码分别拟合后证明几何字节唯一，也不是隐藏未选路线。
6. **白缝与编辑责任。** 自由端 cap 沿全部有限方向检查，仍采用 3 px 上限；只度量
   原图中与实际 tip 连通的局部分量，另一个白缝后的墨迹单独留证。全部旧线、块内
   LINE 成员和已有路径参加重复检查，包括反向端点和不同分段的完整重叠。共享
   来源只许可发生在已证明 core 内，不许可输出有长度的重复线段。生产有限交点
   检查核对本组件新笔之间及与当前正式 owner 的实际交点，要求与来源接点对应；
   与全部旧直线成员的额外点接触由本次保存后独立检查另行核对，见最终结果。

每条横穿 owner 的新笔还须有同组件至少一条完整平行横穿同伴，端点轴夹角≤12°，
该条件不替代端点、来源和枚举证明。组件完整分解先由原始图证明，随后按实际 host
依赖安排几何输出；几何依赖若有环则拒绝。已采用主路径的证明不引用本批新增对象，
因此没有互相引用的无根据证明循环。

这些上限描述本实验支持的有限类别，不是全页通用能力。原生交点重放目前要求直线
段；非零 bulge 圆弧 host 的精确相交、更大循环、较复杂网络另列。像素门不会因
DXF DPI 设置而自动取得扫描缩放不变性；三个固定跨度也不是三份独立来源证据。
生产规则不含样例文件名、
页号、位置、对象 ID、四笔数量或左侧图案模板。

## 保留的最强竞争解释

最有竞争力的另一份完整分解把右斜笔转向附笔的右自由端，并让近水平笔迹结束于
该三向点。这一解释也覆盖全部外边、同样具有四条完整路径；不能仅凭数量排除。
它在三个固定尺度下最大转折约 69.23°，余下附着支臂最小轴分离约 10.39°，同时未满足两项条件；完整链和拒绝依据保留。

若更高分辨率原始扫描或独立绘制顺序证据显示该处本来就是刻意的折笔，当前连续
轴模型可能被推翻。本批四笔是已知开发样例，不是留出验证集；合成例也没有替代
实际原图结果。路线比较前，应由协调者合并双方独立反例再复测。

## 普通采用、导出与冷读

新阶段位于普通流程的 `short_contact_text` 之后，读取真实当前对象，追加独立笔迹。
它不撤回旧对象，不改变原文字采用，也不增加 REVIEW。计划、原图证据及全部 pending
保存到 `evidence/attached_strokes/{plan,adoption}.json`，随 assembly 和导出证据封装。

`attached_stroke_audit.py` 在实际保存后重新读 DXF 与 objects/written 侧车，逐个核对
前置实际对象、块中真实成员、所有新增独立实体、完整首尾和全部顶点；原始像素及
冻结规则必须重新生成完全相同的计划。已发布导出还须核对实际 export envelope
中的 DXF、侧车和证据哈希。复用 assembly 也必须显式保留该阶段 receipt，不能把
缺阶段的旧缓存冒充新算法已执行。
