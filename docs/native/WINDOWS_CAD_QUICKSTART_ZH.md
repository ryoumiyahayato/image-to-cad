# Windows：打开主图，分别修改短字符与接线

适用 **0.3.0-dev / Windows #699（`338a922`）**，目标 CAD 为 **LibreCAD 2.2.1.6**。主图为 **`QUARTER_short_contact_text_17415ed.dxf`**。**[程序下载入口：本版完整交付项](https://github.com/ryoumiyahayato/image-to-cad/actions/runs/45790101851/artifacts/15103796104)**；主图、匹配字体和许可从配套结果包取得。

## 1. 启动、准备字体并打开

1. 将交付项中的完整恢复包解压到新目录，双击 **`Restore-Windows-portable.cmd`**，自动校验、解压和启动程序。另完整解压结果包，保留图纸旁的字体、许可和子目录。
2. 在启动页或文件菜单点击 **“打开已有 DXF / 准备 CAD 字体…”**，选择上述主图；已有图纸无需再识别。找不到 CAD 时点击 **“选择 LibreCAD…”**，选择安装好的 `LibreCAD.exe`。
3. 点击 **“准备 CAD 字体”**。显示 **“需要重新打开 CAD”** 时，先保存工作、完全退出 LibreCAD，再回软件点 **“重新检查”**；显示 **“准备失败”** 时按界面原因处理。显示 **“已准备，可打开 CAD”** 后，点击 **“在 LibreCAD 中打开”**。重复准备保留其他字体及设置。
4. 用 **File → Save as（另存为）** 保存编辑副本，保留原始主图。`Ctrl+Shift+S` 是 Save All。

## 2. 修改完整文字，独立操作图线

- **C07 末端的 S：** 双击文字，直接修改完整内容；本次已实际改成 `K7,03` 并保存重开。
- **LAUNDRY 左侧的 S3：** 是可整组移动、整组删除的独立块。选中组查看块名，再在块列表选同名项进入 **Edit Block**，双击其中的 S 或 3 修改，从 **Drawings** 返回主图；两个字符均为真实 TEXT。
- **整体移动：** 选中完整字组或路径，使用 **Tools → Modify → Move / Copy**，指定参考点和目标点，选择 **Delete Original**，保留原图层和属性。
- **删除整组或整条路径：** 选中目标，用 **Tools → Modify → Delete selected**。删 S3 时贯穿线、承接线和三短划保持；删贯穿路径时完整 S3 保持。完成后普通保存、完全退出 LibreCAD，再重新打开编辑副本检查。
