## 1. 启动、准备字体并打开

1. 将已核验的完整恢复包解压到新目录，双击 **`Restore-Windows-portable.cmd`**，自动校验、解压和启动程序。另完整解压 **`RIGHT_GROUP_DRAWING_1af99e1.zip`**，保留图纸旁的字体、许可和整个 **`librecad-native`** 子目录。它含这张主图匹配的字体缓存；无需重新生成字体。
2. 在启动页或文件菜单点击 **“打开已有 DXF / 准备 CAD 字体…”**，选择上述主图；已有图纸无需再识别。找不到 CAD 时点击 **“选择 LibreCAD…”**，选择安装好的 `LibreCAD.exe`。
3. 点击 **“准备 CAD 字体”**。显示 **“需要重新打开 CAD”** 时，先保存工作、完全退出 LibreCAD，再回软件点 **“重新检查”**；显示 **“准备失败”** 时按界面原因处理。显示 **“已准备，可打开 CAD”** 后，点击 **“在 LibreCAD 中打开”**。重复准备保留其他字体及设置。
4. 用 **File → Save as（另存为）** 保存编辑副本，保留原始主图。`Ctrl+Shift+S` 是 Save All。

## 2. 修改右侧完整文字，独立操作接线

- **右侧 S3 改字：** 选中 LAUNDRY 右侧完整字组，查看其块名；在块列表选择同名项并进入 **Edit Block**，双击 S 或 3，修改内容后从 **Drawings** 返回主图。两个字符都是真实 TEXT。右侧块是独立实例，修改它不会改变左侧 S3 或 C07 的 S。两个成员字高和基线不同，保留原布局即可。
- **整体移动右字组：** 选中完整组，使用 **Tools → Modify → Move / Copy**，指定参考点和目标点，选择 **Delete Original**，保留原图层和属性。贯穿路径和承接横线继续在原位。
- **删除完整右字组：** 选中整组，使用 **Tools → Modify → Delete selected**。从右 D 圆出发的完整路径、圆字和承接横线应保持。
- **移动或删除完整右路径：** 选择从右 D 圆向左弯下、穿过右字组并抵达承接横线的那一条完整路径，再执行移动或删除。该路径是一个 40 顶点对象，圆端和横线端的尾段均在其中；删路径后完整右 S3、圆字、承接横线与其他独立图形应保持。
- **旧字符继续独立编辑：** 左侧 S3 仍是自己的文字组；C07 的 S 仍可双击改字。它们与本批右侧字组分别承担编辑责任。

操作后普通保存，完全退出 LibreCAD，再用新进程打开编辑副本检查。不要覆盖原始主图。
