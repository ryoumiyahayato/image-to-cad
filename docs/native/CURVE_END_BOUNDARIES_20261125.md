## 具体阻塞和共同规则

圆形部分的阻塞在几何测量及冷读重放：接触笔迹可能使同一可靠圆边在重复内外边测量时失败。通用修正利用有证的成对边缘测量和一致重放，原图支持整圆时可先恢复真实 CIRCLE；内字不可靠时仍待修，不根据定位字母填字，不闭合真实开口。

端部处理原先先于 text-contact 长曲线生成。现在最终组装后幂等执行原白缝保护与端接，使后生成的完整路径也得到同一核验。极短延伸仍受**原长度门、全部相交像素为黑墨、唯一可靠来源端口和原末端证据**约束。允许已有开放曲路径保留原顶点后追加短折；LINE 不改原轴。普通连接路径 48 点预算不变；只有原 source plan、路径和裁剪身份均有效的 text-contact，才沿用其已有 256 点表示预算。没有通过案例 ID 或坐标豁免。

T1 原像素支持连接，但目标侧缺失长度 **5.36268 px** 超过原 **4.725 px** 门；本轮未提高长度上限，所以不能称为白缝保护成功。T2 则通过原门，实际增加 1.86269 px 接到圆边。

T3 真缺线已在来源图中找到 250 点、267.2254 px 的路径证据。它在 S 一带不能唯一划分各条分支，下游墙 T 也没有证成为该独立路径的唯一终点；途中局部白孔还受“两端为不同可靠圆”的既有补接门限制。阻塞发生在候选路径划分，尚未进入拟合与正式采用。本轮没有截在 S 顶部，也没有把整个多分支网络塞进一个对象。已有左上路径的 3.93 px 端接改善只记作已有对象修正。
